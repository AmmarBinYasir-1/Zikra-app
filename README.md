🌙 Zikra

Zikra is a beautifully designed Ramadan-themed Digital Tasbih & Hadith web app built to help Muslims maintain daily Dhikr, track progress, and stay spiritually consistent.

✨ Features

📿 Digital Tasbih counter with target goals

📊 Daily tracker & streak system

📖 Authentic Hadith (Arabic + English with references)

🌙 Ramadan special mode & countdown

🕌 99 Names of Allah

🌗 Dark / Light mode

💾 Local storage (works offline)

📱 Fully responsive design

🚀 Installable as PWA

🛠 Built With

HTML5

CSS3

Vanilla JavaScript

LocalStorage
